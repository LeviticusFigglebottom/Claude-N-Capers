# Glossary

| Term | Meaning |
|---|---|
| **Trunk** | Integration branch `claude/dreamy-hamilton-pc7vck`; only the lead pushes. |
| **ENV A/B/C** | The three implementation sessions (Core Systems & AI / Content & Progression / Worlds & Art). |
| **Contract** | A cross-env interface doc in `docs/contracts/`; only the lead edits. |
| **Gate** | Integration test + review criteria that end a phase. |
| **G0–G3** | Level gates: design, greybox, art pass, polish (level_standards.md). |
| **Casing** | Unmasked mode: limited actions, detected only when trespassing. |
| **DR** | Detection risk 3–75, derived from total concealment. |
| **Detection meter** | Per-observer, per-crew fill 0..1; "?" filling, "!" full. |
| **Pager** | Radio call after killing/dominating a guard; 4 answerable per heist, team-wide. |
| **Juggling** | Two crew overlapping holds on one pager so releasing doesn't alarm. |
| **Stimulus** | Something NPCs can perceive (corpse, bag, broken glass, drill...). |
| **NoiseEvent** | The only way sound alerts NPCs; footsteps never create one. |
| **Variant / VariantSlot** | Per-run dynamic variable / map placeholder for one option. |
| **Rare event** | Low-chance good/bad per-run outcome (vault open, extra guard...). |
| **Assault phases** | CONTROL → ANTICIPATION → BUILD → SUSTAIN → FADE. |
| **Drama** | Director pressure metric from player damage taken. |
| **Specials** | Phantom (cloaker), Stinger (taser), Bulwark (shield), Wrecker (dozer), Longshot (sniper), Corpsman (medic), Commander Brandt + Aegis (captain). |
| **Armor gating** | A normal enemy hit is capped at remaining armor. |
| **Custody / trade** | Out of play after 4th down; hostage trade (or timer on low difficulty) to return. |
| **Modifier key** | Registry key granted by skills/perks/assets, queried by systems. |
| **Loadout resolver** | ENV B's single source of truth for weapon stats, concealment, DR. |
| **Prefab** | ENV A gameplay scene with a `Visual` slot for art. |
| **Dressing kit** | Per-room-purpose prop set with required items and density rules. |
| **Mercer** | Our handler on comms (Bain analog). |
| **The stash** | Offshore-account analog (80% of payout). |
| **Board** | Contract map in the safehouse (CRIME.NET analog). |
